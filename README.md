# N8nPort — Managed n8n Hosting

**[n8nport.com](https://n8nport.com)** gives freelancers, agencies, developers, and small businesses a dedicated, managed [n8n](https://n8n.io) workspace — HTTPS, scheduled backups, runtime health monitoring, and Google sign-in included — plus a catalogue of editor-curated, one-click-installable workflow templates.

No Docker, no reverse proxy, no server maintenance. You bring your own third-party API keys (they stay inside your own workspace, never with us); we handle the runtime.

## Why N8nPort

- **Dedicated workspace** — your own isolated n8n instance with defined CPU/RAM, not a shared multi-tenant pod.
- **Unlimited executions** — unlike capped cloud plans, you're not billed per workflow run.
- **One-click workflow templates** — editor-reviewed automations delivered straight into your workspace.
- **Managed operations** — HTTPS, scheduled backups, and runtime health monitoring included on every plan.
- **You keep your credentials** — third-party API keys and OAuth tokens live in your own n8n credential manager, never collected by us.

Plans start at **$10/month**. See [current pricing](https://n8nport.com/pricing).
